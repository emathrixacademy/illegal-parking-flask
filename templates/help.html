How to Filter Violations

Use the filter bar at the top to narrow down results. Here's how each filter works:

Filter bar

All Types ▾ All Hours ▾ All Days ▾ All Cameras ▾ Filter Clear
Choose a date range — Click the "From" and "To" date fields. A calendar picker will appear. Select the start and end dates to define your range.
Pick optional filters — Use the dropdowns to filter by vehicle type (Car, Truck, Motorcycle...), time of day (morning, afternoon...), day of week, or specific camera.
Click Filter — The table updates to show only matching violations.
See active filters — Applied filters appear as tags above the table. Click the × on any tag to remove that filter.

Admin Panel (Incident Review)

Review, approve, or reject AI-detected violations. This is where you make official decisions on each incident.

Go to Admin Panel

How to Review an Incident

Click an incident row in the table on the left. The right panel loads its details: image, video, vehicle type, confidence, and plate number.
Review the evidence — Look at the captured image and video clip. Check if the vehicle is actually blocking the road.
Choose a decision by clicking one of the three buttons below:
Admin decision buttons
Approved
Yes, this is a real violation. Confirm it.
Rejected
False detection. The AI made a mistake.
Investigate
Not sure yet. Flag for further review.
Save Decision
All decisions are logged for audit purposes.

Generate PDF Report

Download a professional PDF report of violations for any time period. Click the Download Report button at the bottom of the incident list to open the report panel.

Report configuration
Choose Period — Day, Week, Month, or Custom Range
Set the date — Pick the start date (for Week/Month, the report covers the full period from that date)
Optional filters — Narrow by Vehicle Type, Camera, or Review Status
Click Download PDF — The report file downloads automatically
Weekly reports: Select the start date (e.g., Monday). The report automatically covers 7 days from that date.
