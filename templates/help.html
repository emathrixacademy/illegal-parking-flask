Step-by-Step: How to Use the Calendar

Navigate to the right month — Use the arrows to go to previous or next month. Click Today to jump back to the current date.
Look at the colors — Scan the calendar for red (high-incident) and yellow (some incidents) dates. Green dates are clear.
Click a date — The right panel updates to show the selected date, total incident count, which cameras were involved, and a scrollable list of every incident.
Browse incidents — Each incident card shows the camera name, time, vehicle type, tracker ID, confidence score, and plate number (if detected). Scroll down to see all incidents for that day.
View evidence — Each incident has a captured image (screenshot from the camera) and a video clip (60-second recording) that you can view directly in the panel.
Search by plate — Use the Plate Number Search box in the side panel to find all incidents involving a specific vehicle (e.g., type UAP 430 or ABC-1234).

The Settings page has 5 sections that control how the system detects violations, sends alerts, manages cameras, and handles cloud storage. Each section is explained in detail below.

1. General Settings

These two values control when the AI flags a parked vehicle as a violation and how often it re-captures the same vehicle.

General Settings panel
Violation Time Threshold (seconds)
300
Time before a parked vehicle is flagged as a violation
Repeat Capture Interval (seconds)
300
Cooldown between logging the same vehicle
Save Settings
Database: Violation=300s, Repeat=300s
Violation Time Threshold — How many seconds a vehicle must stay parked in the detection zone before the AI records it as a violation. Example: if set to 300 (5 minutes), a car parked for only 3 minutes will NOT be flagged. Increase this to reduce false detections; decrease it to catch shorter violations. Repeat Capture Interval — After a vehicle is recorded as a violation, the system waits this many seconds before capturing it again. Prevents duplicate entries. Example: at 300 seconds, the same car won't be logged twice within 5 minutes.
Change the number in either field (in seconds)
Click Save Settings
The green text below the button confirms the saved values: Database: Violation=300s, Repeat=300s
