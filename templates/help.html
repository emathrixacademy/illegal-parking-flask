Welcome to DECONGESTILAGUNA

This system monitors roads in Brgy. Kanluran, Taguig using AI-powered CCTV cameras to detect illegal parking and road-blocking violations. Below is a complete guide to help you navigate every feature.

Tip: Click the icons throughout the system for quick explanations of each feature.

User Roles

The system has three access levels:

  • Admin — Full system control: manage users, review incidents, configure cameras, AI settings, generate reports, and manage cloud media.
  • Operator — Monitor and respond: view live feeds, review/approve incidents, configure alerts, and access settings.
  • Viewer — Read-only access: view the dashboard, violations list, and calendar. Cannot modify settings or review incidents.

Dashboard

The main monitoring hub showing live camera feeds and real-time analytics.

Go to Dashboard

Live Camera Feeds

View real-time footage from all connected CCTV cameras. Each feed has zoom controls (+/-) and a reconnect button if the stream drops. The primary camera (Camera 1) is displayed larger at the top.

Health Status Bar

Shows the system health (Healthy/Warning/Critical), Pi connection status with last heartbeat time, and a real-time clock in Philippine Standard Time.

Analytics Dashboard

  • Summary Cards — Key metrics: total violations, average duration, peak hour, and worst day of the week.
  • Vehicle Type Chart — Pie chart showing the breakdown of violation types (Car, Truck, Motorcycle, etc.).
  • Hourly Heatmap — 30-day grid showing when violations are most frequent by hour and day.
  • Daily Trend — Line chart tracking daily violation counts over 30 days.
  • Camera Comparison — Bar chart comparing violation counts across cameras.

AI Model Performance

Displays YOLOv8 vehicle detection stats (total detections, confidence levels) and EasyOCR plate recognition stats (plates read, success rate, unique plates).

Violations

Browse, search, and filter all recorded parking violations.

Go to Violations

Database Records Tab

The main table shows all violations with camera, vehicle type, timestamp, confidence score, and review status. Click any row to see full details including the captured image and video clip.

Filtering

  • Date Range — Filter violations between specific dates.
  • Vehicle Type — Show only specific vehicle types (Car, Motorcycle, Truck, etc.).
  • Time of Day — Filter by hour range (morning, afternoon, evening, night).
  • Day of Week — Show violations for a specific day (e.g., only Fridays).
  • Camera — Filter by specific camera location.
  • Today Only — Quick filter showing only today's violations.

Active filters appear as removable tags above the table. Click the X on any tag to remove that filter.

Capture Images Tab

Browse violation images organized by date. Use the plate number search to find specific vehicles across all records.

Calendar

Visual timeline of incidents organized by date with color-coded severity indicators.

Go to Calendar

Calendar Grid

Each date cell shows the incident count with color coding: green (0 incidents), yellow (1-3), red (4+). Click any date to view its incidents in the side panel.

Incident Overview Panel

When a date is selected, the right panel shows: date, total incident count, cameras involved, and a scrollable list of all incidents with images and video clips.

Plate Number Search

Search for a specific license plate number (e.g., ABC-1234) to find all recorded incidents involving that vehicle.

Settings

Configure system behavior, alerts, cameras, and AI detection.

Go to Settings

General Settings

Set the violation time threshold (how long a vehicle must be stationary before it's flagged) and repeat capture interval (minimum time between re-detections of the same vehicle).

Alert Configuration

  • Email Alerts — Enable Gmail-based email notifications. Requires a Gmail address and App Password (not your regular password). Add recipient emails separated by commas.
  • SMS Alerts — Enable text message alerts via UniSMS or TextBee providers. Requires provider API credentials.
  • Cooldown — Minimum time between consecutive alerts to prevent spam.
Tip: Use the "Test SMTP" button to verify your email configuration before relying on it for live alerts.

Camera Management

View, add, edit, or remove cameras. Each camera has an ID, display name, location, RTSP stream URL, and status (active/inactive).

AI Detection Controls

  • Detection Engine — Toggle the AI detection on or off.
  • Cloud Uploads — Pause/resume Cloudinary uploads to save cloud storage credits.
  • Confidence Threshold — Adjust how confident the AI must be before recording a violation (lower = more detections but more false positives).

Cloud Media Management

Browse and selectively delete uploaded violation images and videos from Cloudinary to manage storage. Filter by age (7/14/30 days) and delete in bulk.

Admin Panel (Incident Review)

Review, approve, or reject AI-detected violations.

Go to Admin Panel

Incident List

Browse all detected road-blocking incidents. Filter by date and review status (For Review, Approved, Rejected, Needs Investigation). The total count updates as you filter.

Reviewing an Incident

  1. Click an incident row in the table to load its details on the right panel.
  2. Review the captured image, video clip, vehicle type, confidence score, and plate number.
  3. Choose a decision: Approved (confirmed violation), Rejected (false detection), or Investigate (needs further review).
  4. Click "Save Decision" to record your review.

Generate PDF Report

Download a professional PDF report of violations for a specific period (Day, Week, Month, or Custom Range). Filter by vehicle type, camera, and review status. Reports include summary statistics, violation type breakdown, daily counts, and a detailed incident log.

Tip: For weekly reports, select the start date of the week. The report automatically covers 7 days from that date.

User Management

Manage system users and monitor activity.

Go to User Management

Users Table

View all registered users with their username, display name, email, role, status, and last login time. Use the edit button to change roles or the delete button to remove users.

Adding Users

Click "Add User" to create a new account. Assign a username, display name, email, password, and role (Admin, Operator, or Viewer).

Activity Log

Tracks all system actions: logins, incident reviews, user creation/deletion, and settings changes. Shows timestamp (PHT), user, action, and details.
